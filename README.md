# SPI (Serial Peripheral Interface) Protocol - Verilog

## Overview
The Serial Peripheral Interface (SPI) is a synchronous serial communication protocol used for short-distance communication between microcontrollers and peripheral devices. It supports high-speed data transfer and full-duplex communication.

This project implements the SPI protocol in Verilog HDL and demonstrates communication between a Master and Slave device.

---

## Features

- Synchronous serial communication
- Full-Duplex data transfer
- Four-wire communication protocol
- Supports one Master with multiple Slaves
- High-speed communication (up to 10 Mbps)
- Master provides the clock signal
- Supports 8-bit and 16-bit data transfer

---

## SPI Signals

| Signal | Description |
|---------|-------------|
| **MOSI** | Master Out Slave In – Data sent from Master to Slave |
| **MISO** | Master In Slave Out – Data sent from Slave to Master |
| **SCLK** | Serial Clock generated by the Master |
| **SS/CS** | Slave Select / Chip Select (Active Low) |

---

## SPI Communication

The Master initiates communication by pulling the **Slave Select (SS/CS)** line LOW.

Data is transferred synchronously using the clock generated by the Master.

Both Master and Slave can transmit and receive data simultaneously.

---

## SPI Modes

SPI supports four communication modes based on:

- **CPOL (Clock Polarity)**
- **CPHA (Clock Phase)**

| Mode | CPOL | CPHA |
|------|------|------|
| Mode 0 | 0 | 0 |
| Mode 1 | 0 | 1 |
| Mode 2 | 1 | 0 |
| Mode 3 | 1 | 1 |

---

## Advantages

- Full-duplex communication
- High-speed data transfer
- No Start and Stop bits required
- Simple hardware implementation
- Easy synchronization using Serial Clock

---

## Disadvantages

- Requires four communication wires
- Separate Slave Select line for each slave
- No built-in error detection
- Limited communication distance
